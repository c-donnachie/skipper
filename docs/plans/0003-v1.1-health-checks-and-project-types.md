## Context

Audit of not-pato (Expo app on skipper) and rail-api (B2B API, hand-documented, didn't adopt skipper) surfaced three high-impact gaps: stack freeze, doc/code drift, and no structure for service/library projects. This plan tracks shipping the fixes for v1.1.

## Steps

- [x] 1. `lib/stack-sync.sh` — package.json ↔ stack block diff (curated lib dictionary, JSON out).
- [x] 2. `skills/stack-sync/SKILL.md` — interprets drift, offers in-marker fix on confirmation.
- [x] 3. `lib/docs-doctor.sh` — stale / stub / broken-link / empty-dir checks (JSON out).
- [x] 4. `skills/docs-doctor/SKILL.md` — severity table, routes fixes to `/skipper:update`.
- [x] 5. `skills/init-structure/SKILL.md` — project types app/service/library with type-specific folders + READMEs.
- [x] 6. Wire-in: README commands table, Components count, `Stop` hook mentions docs-doctor.
- [x] 7. CHANGELOG 1.1.0 + bump `plugin.json` to 1.1.0.
- [x] 8. Validate scripts against not-pato + rail-api (real fixtures).

## Critical files

## Proactive mode (added)

- [x] 9. Make hooks proactive (Tier 2, opt-out) — ADR 0009.
  - `hooks/docs-sync.sh` (PostToolUse) injects `additionalContext` on app-code edits.
  - `hooks/suggest.sh` (Stop) becomes the enforcer: exit 2 + stderr directive when code in a documented area changed without `docs/` being touched; loop-safe (`stop_hook_active`, 30-min marker, docs-touched skip).
  - `hooks/session-start.sh` injects the standing sync directive.
  - `hooks/hooks.json`: registered docs-sync, Stop timeout 5→10s.
  - Validated in a controlled temp repo: exit-2 directive fires, loop-guard holds, opt-out falls back to the historic suggestion. Fixed: detection switched to `git status --porcelain` so newly-Written (untracked) files count.
